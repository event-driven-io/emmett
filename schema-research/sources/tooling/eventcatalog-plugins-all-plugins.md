# All EventCatalog plugins

Copy as Markdown[View as Markdown](/docs/plugins/all-plugins.md)

***

Automate and sync your data from a wide range of systems to EventCatalog.

| Plugin                                                                        | Description                                                                |
| ----------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| [AsyncAPI Plugin](/docs/plugins/asyncapi/intro.md)                            | Generate documentation from your AsyncAPI files                            |
| [OpenAPI Plugin](/docs/plugins/openapi/intro.md)                              | Generate documentation from your OpenAPI files                             |
| [GraphQL Plugin](/docs/plugins/graphql/intro.md)                              | Generate documentation from your GraphQL files                             |
| [Apicurio Registry](/docs/plugins/apicurio/intro.md)                          | Import schemas and specifications from Apicurio Registry into EventCatalog |
| [Azure Schema Registry](/docs/plugins/azure-schema-registry/intro.md)         | Import schemas from Azure Schema Registry into EventCatalog                |
| [Github Plugin](/docs/plugins/github/intro.md)                                | Sync your schemas from GitHub to EventCatalog                              |
| [Backstage Plugin](/docs/plugins/backstage/overview.md)                       | Embed EventCatalog documentation and visualizations in Backstage           |
| [Amazon EventBridge](/docs/plugins/eventbridge/intro.md)                      | Sync Amazon EventBridge schemas to EventCatalog                            |
| [Amazon API Gateway](/docs/plugins/amazon-apigateway/intro.md)                | Generate documentation from your Amazon API Gateway                        |
| [Confluent Schema Registry](/docs/plugins/confluent-schema-registry/intro.md) | Sync your schemas from Confluent Schema Registry to EventCatalog           |
| [EventCatalog Federation](/docs/federation/overview.md)                       | Merge multiple EventCatalog instances into a single catalog.               |
