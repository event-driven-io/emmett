Event Storming
Event Storming is a collaborative workshop technique where teams map out key domain events in a business process.

Domain Driven Design
DDD is a way to design software by focusing on the real-world business, making sure the software closely matches the needs of the organization.

Event Modeling
Event Modeling is a technique for defining a system's behavior by mapping out state changes over time, it helps align stakeholders and enables fixed cost projects.
